проверка связи с компаньоном…

Ещё один шаг — и готово

Само расширение уведомления не отправляет — этим занимается небольшая программа-компаньон на вашем компьютере: именно она слушает вашего AI-агента и решает, когда стоит вас отвлечь. Без неё расширение просто ничего не будет делать.

⬇ Скачать компаньон (Windows, ~55 МБ)

Один файл. Ничего устанавливать в систему не нужно.

  1. Скачайте и дважды кликните файл
    Он сам распакует расширение, зарегистрирует компаньон и откроет нужные окна — ничего печатать в консоли не придётся.
  2. В открывшемся окне chrome://extensions включите Developer mode
    Переключатель в правом верхнем углу страницы. Это разово и безопасно — Chrome специально требует это для расширений не из магазина, чтобы никто не мог поставить их тихо.
  3. «Load unpacked» → выберите уже открытую папку
    Установщик сам откроет её в проводнике — просто выберите ту же папку в диалоге Chrome.
  4. Подключите хуки своего агента
    Установщик напечатает готовый сниппет с уже подставленным путём — останется вставить его в конфиг Claude Code/Cursor/Copilot/Codex.
Уже есть Node.js и хотите поставить из исходников, или нужна версия для macOS/Linux? Полная инструкция — в README проекта.
Что-то не заработало или есть пожелание — напишите в issues, или прямо в Telegram командой /feedback, если подключили общего бота. В настройках расширения есть кнопка «Скопировать диагностику» — с ней разобраться сильно быстрее.
