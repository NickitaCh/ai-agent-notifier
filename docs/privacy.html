Nothing leaves your computer.

This policy is short because the product is simple: a local extension talking to a local process, with no server on the other end.

AI Agent Notifier does not collect, store, transmit, or sell any user data. There is no backend, no analytics, and no network communication of any kind beyond messages your own computer sends to itself.

What the extension does

AI Agent Notifier pairs a Chrome extension with a small companion program (the “host”) that you install and run on your own machine. The host listens for hook events from AI coding agents — Claude Code, Cursor, GitHub Copilot CLI, OpenAI Codex CLI — running locally, and the extension shows a notification or badge when an agent needs your attention.

Specifically

  • Minimal permissions. Only nativeMessaging, notifications, and alarms — no tabs, scripting, or host_permissions, so the extension cannot read page content or browsing history.
  • No outbound network code. The extension's source contains no fetch, XMLHttpRequest, or any other call that reaches the internet.
  • Local-only transport. Extension and host talk over a TCP socket on 127.0.0.1:8765, protected by a random token generated on first run and stored in your local profile. It never accepts a connection from outside the machine.
  • Logs stay put. Tool names, working-directory paths, and short summaries of what an agent is asking are written only to local log files (%APPDATA%\ai-agent-notifier\*.log and platform equivalents), for your own troubleshooting.
  • Diagnostics are opt-in, every time. The popup's “Copy diagnostics” button copies a local log excerpt to your clipboard on click, for you to paste wherever you choose. Nothing uploads automatically.
  • No accounts. No sign-in and no persistent identifier tied to you beyond the random local auth token above.

Third parties

None. No analytics SDKs, crash reporters, ad networks, or other third-party services are integrated into the extension or the host.

Changes to this policy

If this ever changes — for example, an optional future notification channel that requires a network call — this document will be updated first, the change described in the project’s README, and the revision history kept visible in the GitHub repository.

С вашего компьютера ничего не уходит.

Эта политика короткая, потому что продукт простой: локальное расширение общается с локальным процессом, и на другом конце нет никакого сервера.

AI Agent Notifier не собирает, не хранит, не передаёт и не продаёт никакие пользовательские данные. У расширения нет бэкенда, нет аналитики и нет никакой сетевой активности, кроме сообщений, которые ваш компьютер отправляет сам себе.

Что делает расширение

AI Agent Notifier связывает расширение Chrome с небольшой программой-компаньоном («хостом»), которую вы сами устанавливаете и запускаете на своей машине. Хост слушает события хуков от ИИ-агентов для программирования — Claude Code, Cursor, GitHub Copilot CLI, OpenAI Codex CLI — работающих локально, а расширение показывает уведомление или бейдж, когда агенту нужно ваше внимание.

Конкретно

  • Минимум разрешений. Только nativeMessaging, notifications и alarms — без tabs, scripting или host_permissions, поэтому расширение не может читать содержимое страниц или историю браузера.
  • Никакого исходящего сетевого кода. В исходном коде расширения нет ни fetch, ни XMLHttpRequest, ни любого другого вызова, который выходит в интернет.
  • Только локальный транспорт. Расширение и хост общаются через TCP-сокет на 127.0.0.1:8765, защищённый случайным токеном, который генерируется при первом запуске и хранится в вашем локальном профиле. Соединения снаружи машины не принимаются.
  • Логи остаются на месте. Имена инструментов, пути рабочих директорий и короткие сводки того, о чём спрашивает агент, записываются только в локальные файлы логов (%APPDATA%\ai-agent-notifier\*.log и аналоги на других платформах) — для вашей же диагностики.
  • Диагностика — только по вашему клику. Кнопка «Скопировать диагностику» в popup копирует выдержку из локального лога в буфер обмена по вашему нажатию, чтобы вы сами вставили её куда захотите. Автоматической отправки нет.
  • Без аккаунтов. Нет входа и нет постоянного идентификатора, привязанного к вам, кроме случайного локального токена авторизации, описанного выше.

Третьи стороны

Их нет. В расширение и хост не встроены ни SDK аналитики, ни сборщики крашей, ни рекламные сети, ни какие-либо другие сторонние сервисы.
